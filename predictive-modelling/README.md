# 🚢 Titanic Survival Prediction Using Machine Learning

## 📌 Project Overview
This project focuses on building a machine learning model to predict Titanic passenger survival using supervised learning techniques. The goal is to analyze passenger data and develop a classification model.

---

## 🎯 Objective
To develop a classification model that predicts whether a passenger survived based on features such as age, gender, passenger class, and fare.

---

## 📂 Dataset
The Titanic dataset contains the following features:
- PassengerId  
- Survived  
- Pclass  
- Name  
- Sex  
- Age  
- SibSp  
- Parch  
- Fare  
- Cabin  
- Embarked  

---

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn  

---

## ⚙️ Machine Learning Workflow

### 📥 Data Preprocessing
- Handling missing values (Age, Cabin, Embarked)  
- Encoding categorical variables (Sex, Embarked)  
- Feature engineering (FamilySize, Title extraction)  

---

### 🤖 Model Building
Applied classification algorithms:
- Logistic Regression (baseline model)  
- Decision Tree Classifier  
- Random Forest Classifier
